# Quantum ESPRESSO reference data

The inputs and CSV files in this directory are teaching reference data produced with Quantum ESPRESSO 7.5. `convergence.json` is generated by `scripts/generate-qe-convergence.mjs` from fresh `pw.x` calculations.

## Sweep design

- Cutoff: `ecutwfc = 20, 25, 30, 40, 50 Ry`; `ecutrho = 8 × ecutwfc`; cell fixed at 14 Å.
- Vacuum: cubic cells of 10, 12, 14, 16, and 18 Å; `ecutwfc = 30 Ry` and `ecutrho = 240 Ry`.
- Fixed molecular geometry, fixed occupations, and `K_POINTS gamma` throughout.
- Systems: benzene, ethylene, formaldehyde, and ammonia.

The JSON preserves total energy, frontier eigenvalues, all computed band eigenvalues, SCF iterations, estimated accuracy, completion flags, and recorded wall time for every point. Wall time is machine-dependent and is included only to make the replay record complete.

## Rebuilding

Set `VLAB_QE_PSEUDO_DIR` to a directory containing the pseudopotentials named in each input, then run:

```bash
VLAB_QE_PSEUDO_DIR=/path/to/pseudo \
VLAB_QE_MIRROR_PATH=src/data/qe/convergence.json \
node scripts/generate-qe-convergence.mjs /tmp/vlab-qe-convergence.json
```

The temporary file checkpoints after each successful run. The mirror is written only after the entire sweep is complete, so the application never imports a half-built dataset. Never replace the data with hand-adjusted values; if settings change, regenerate the complete sweep and update the lab documentation.
